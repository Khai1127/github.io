Chào các bạn, hiện nay tại các nhà máy điện và trạm điện đang vận hành sử dụng rất nhiều các role và các chức năng khác nhau: mình chia sẻ cách truy cập và lấy dữ liệu từ role Sell nhé!

  1. Sự chuẩn bị cần thiết:

    • Laptop đã cài sẵn phần mềm Quickset
    • Cáp kết nối (các bạn mua đủ cả 2 loại cáp này mới kết nối được nhé: Cáp Chuyển USB 2.0 to RS232 Ugreen 20211 và Cáp chéo DB9 đực cái)

  2. Các bước thực hiện:

    Bước 1: kết nối cáp truyền thông giữa role với máy tính, cách kiểm tra như sau:
    1.1   Click chuột phải vào Computer, chọn Manage :

    1.2    Chọn Device Maneger-Port (Com & LPT) :

    Nếu hiện SEL CP210x USB to UART Bridge (Com 11) thì việc kết nối đã thành công.


    Bước 2: Truy cập vào phần mềm AcSELerator QuickSets


    2.1    Click đúp vào biểu tượng để khởi động phần mềm.
    2.2   Sau khi phần mềm hoàn tất khởi động có giao diện như sau:

    2.3   Chọn communication:

    Cài đặt thông số như sau:
    • Active connection type: Serial ;
    • Device: Chọn cổng Com đã kết nối ở bước 1;
    • Data speed: 38400;
    • Các mục còn lại để mặc định;
    • Chọn Apply - Ok.

    2.4   Chọn Tool - Event - Get event file

    2.5  Sau khi chọn Get Event File giao diện của phần mềm như sau:
    Phần Event History là danh sách các sự cố đã xảy ra. Chọn sự cố muốn tải về và chọn Get Select Event

    2.6   Sau khi chọn Get Select Event giao diện của phần mềm như sau:

    Mục Save Location chọn thư mục lưu, chọn Save
